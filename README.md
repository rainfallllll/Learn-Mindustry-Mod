## 如何本地打开

1. **直接浏览门户首页**：双击 `index.html`，在浏览器中打开，点击卡片进入各教程
2. **直接阅读单个教程**：进入对应目录，双击 `.html` 文件即可阅读
3. **Markdown 版本**：每个教程目录下都有 `.md` 源文件，适合在编辑器中查看或二次编辑

## 版本声明

- **游戏版本**：主线教程基于 Mindustry v159.7（HEAD `b3317f3`）；**v160 变更速查**基于 Mindustry v160（HEAD `0ac15152d8`）
- **JDK**：17+（必须，Mindustry 用 Java 17 编译）
- **Gradle**：7.5+（或使用项目自带 wrapper）
- **所有源码行号**：均对对应版本，游戏升级后行号可能偏移但 API 结构不变
