0. 先搞懂 Mindustry 的信息 UI 是怎么分层的

在动手前，记住这张调用链，后面四块全是它的局部扩展：

玩家点了一个建筑
  └─ BuildingComp.display(Table)            ← 第二块要覆写的就是它
       ├─ 顶部：建筑图标 + 名字
       ├─ displayBars(Table)                 ← 第一块的状态条从这里被画出来
       │     └─ 遍历 Block.listBars()
       │            └─ 每个 Bar 来自 Block.addBar(...)   ← 第一块注册
       └─ displayConsumption(...)           ← 默认的电/液/物品消耗

游戏内数据库（图鉴）里看一个建筑
  └─ Block.setStats()                        ← 第三块要覆写的就是它
       └─ stats.add(Stat, StatValue)         ← 用 StatValues.* 造值

玩家想看全局数据
  └─ 你 new 一个 Dialog                       ← 第四块
       └─ dialog.cont 里摆 Table

一句话：状态条走 addBar，点建筑弹窗走 display，图鉴走 setStats，独立大窗口走 Dialog。

第一块：建筑状态条自定义（温度条 / 热量条 / 效率条）

目标

给建筑脚下/信息面板里加一条自己的进度条。我们要做一条"温度条"：红色填充，按 0 ~ maxTempK 映射成 0~1。

完整可复制代码

package com.example.blocks;

import arc.graphics.Color;
import arc.math.Mathf;
import mindustry.world.Block;
import mindustry.world.meta.StatUnit;

public class ExampleBlock extends Block {

    /** 温度上限（K），0~1 映射的分母 */
    public float maxTempK = 800f;

    public ExampleBlock(String name) {
        super(name);
        // 不要在这里 addBar！原因见"坑"。
    }

    // ★ 关键：覆写 setBars()，先调 super 再加自己的条
    @Override
    public void setBars() {
        super.setBars();   // 必须先调，否则血条/电条/物品条全没了

        addBar("temperature", (ExampleBuild entity) -> new Bar(
            () -> "温度",                 // 条上的名字
            () -> Color.red,              // 条颜色（可随温度变）
            // ★ fraction 必须返回 0~1！
            () -> Mathf.clamp(entity.curTempK / entity.block.maxTempK)
        ));
    }

    public class ExampleBuild extends Building {
        public float curTempK;
    }
}

只讲 2~3 个新 API

① Block.addBar(String name, Func<T, Bar> sup) —— Block.java:677

public <T extends Building> void addBar(String name, Func<T, Bar> sup){
    barMap.put(name, (Func<Building, Bar>)sup);
}
  • 泛型 <T extends Building>，lambda 里直接写成 (YourBuild entity) -> ...，强转在方法内部 :678 完成。
  • 第二个参数是懒求值工厂：每帧画条时才调一次，返回 Bar；返回 null 就不画。

② Bar 两个构造函数 —— Bar.java:23 与 :31

// 静态版：名字/颜色不变
public Bar(String name, Color color, Floatp fraction)            // :23
// 动态版：名字/颜色每帧可变（做温度变色用这个）
public Bar(Prov<CharSequence> name, Prov<Color> color, Floatp fraction)  // :31
  • 第三个参数 Floatp 即 () -> float，必须返回 0~1。
  • 链式：blink(Color)(Bar.java:71，返回 Bar)、snap()(:57，void)、outline(Color,float)(:61)。

③ BuildingComp.displayBars(Table) —— BuildingComp.java:1667。一般不用覆写，它在 display() 内部 :1577 被调用，你 addBar 注册的条会自动按顺序画出来。

坑（萌新必踩）

  1. 不要在构造函数里 addBar！正确位置是覆写 setBars() 并先 super.setBars()。因为 afterPatch() 在 Block.java:769 会先 barMap.clear() 再 setBars()(:770)；构造函数里加的会被清掉。
  2. fraction 必须 0~1，不是物理量本身。
  3. 泛型 T 要匹配你的 Build 子类。
  4. 字段名是 barMap(Block.java:422)，不是 bars。

深入：官方血条 Block.java:707、电条 :713、物品条 :722、液体条 :690/:699；Bar 全部方法见 Bar.java。

第二块：建筑信息面板自定义

目标

点击建筑，在默认信息后追加两行：温度: XXX K、热流: XXX J/t。

完整可复制代码

// 放在 Build 内部类里
@Override
public void display(Table table) {
    super.display(table);          // ★ 必须先调，否则默认信息全丢

    table.row();
    table.left().label(() ->
        "温度: " + String.format("%.1f K", thermal.getTemperatureK())
    );

    table.row();
    table.left().label(() ->
        "热流: " + String.format("%.1f J/t", thermal.pendingDeltaQ)
    );
}

只讲 2~3 个新 API

① BuildingComp.display(Table) —— BuildingComp.java:1561，点建筑后信息面板的绘制入口。你在它末尾接着画。

② Table 四件套：add() 塞元素、row() 换行、left()/right()(Table.java:786/:800) 对齐、label(Prov<CharSequence>)(Table.java:285) 动态文字每帧刷新。文字支持 [颜色]...[] 富文本。

坑

  1. 必须 super.display(table); 放第一行，否则图标/名字/状态条/消耗全消失。
  2. 新加一行先 table.row() 再 add/label。
  3. 刷新用 label(() -> ...)，不要 add("固定串")。
  4. 覆写的是 Build 内部类的 display，不是 Block。

第三块：数据库信息呈现自定义（图鉴）

目标

在图鉴点开建筑时，除默认信息外显示 热容 C、airU、maxHeatRate 等自定义静态条目。

完整可复制代码

import mindustry.world.meta.Stat;
import mindustry.world.meta.StatUnit;
import mindustry.world.meta.StatValues;

public class ExampleBlock extends Block {

    // ★ 自定义 Stat（类，不是枚举）。new 出来就自动注册
    public static final Stat heatCapacityStat = new Stat("thermalHeatCapacity");
    public static final Stat airUStat          = new Stat("thermalAirU");
    public static final Stat maxHeatRateStat   = new Stat("thermalMaxHeatRate");

    // 块级常量：图鉴在还没造建筑时就要显示
    public float heatCapacity = 2000f;
    public float airU = 0.05f;
    public float maxHeatRate = 50f;

    @Override
    public void setStats() {
        super.setStats();   // 必须先调

        stats.add(heatCapacityStat, "%.0f J/K", heatCapacity);
        stats.add(airUStat, "%.3f J/(t·格·K)", airU);
        stats.add(maxHeatRateStat, StatValues.number(maxHeatRate, StatUnit.none));
    }
}
中文名：Stat.localized()(Stat.java:126) 去 bundle 找 "stat."+name（转小写）。在 bundle.properties 加 stat.thermalheatcapacity=热容 C 等即可。

只讲 2~3 个新 API

① Block.setStats() —— Block.java:641，内容加载时只跑一次。

② Stat —— Stat.java（是类不是枚举）。构造 Stat(String,StatCat)(:115) / Stat(String)(:122)，构造即自动注册进 Stat.all。

③ StatValues 工厂 —— StatValues.java：string():35、bool():40、number():69、liquid():115、squared():48。往 stats 加值：stats.add(Stat,fmt,args)(Stats.java:93) 或 stats.add(Stat,StatValue)(Stats.java:104)。

坑

  1. setStats() 内容加载时跑一次，不能读运行时实例温度，只能放块级常量。
  2. 要显示的常量必须在 Block 上，不能在 Build 里。
  3. Stat 是类不是枚举，new Stat("xxx") 即可，别找 Stat.values()。
  4. 先 super.setStats();。

// v160 新写法示例
@Override
public void setStats(){
    super.setStats();   // ← useCategories 已自动开，不用手写

第四块：自定义窗口 / 悬浮面板

目标

弹出独立大窗口"热网总览"，列出场上所有热力建筑温度/状态。

完整可复制代码

package com.thermal.mod.ui;

import arc.scene.ui.Dialog;
import arc.scene.ui.layout.Table;
import com.thermal.mod.ThermalModMain;
import com.thermal.mod.core.ThermalBuilding;
import mindustry.gen.Building;

public class ThermalOverviewDialog extends Dialog {

    public ThermalOverviewDialog() {
        super("热网总览");          // Dialog(String) —— Dialog.java:65
        cont.pad(14f);              // ★ 正文加在 cont，不是 this！

        Table list = new Table();
        list.left();
        cont.top();
        cont.defaults().width(340f);
        cont.add(list).growX();
        cont.row();

        Runnable rebuild = () -> {
            list.clearChildren();
            list.left();
            var all = ThermalModMain.thermalSystem.allBuildings();
            if (all.isEmpty()) { list.add("[lightgray]场上还没有热力建筑。"); return; }
            for (ThermalBuilding tb : all) {
                Building b = tb.asBuilding();
                float t = tb.getThermal().getTemperatureK();
                list.left().add(b.block.localizedName).padRight(10);
                list.left().label(() -> String.format("%.1f K", t));
                list.row();
            }
        };
        cont.update(rebuild);       // 每帧刷新

        buttons.defaults().size(140f, 60f);
        buttons.button("关闭", () -> hide());
    }
    // 调用：new ThermalOverviewDialog().show();
}

配套给 ThermalSystem 加访问器：public Seq<ThermalBuilding> allBuildings(){ return buildings; }

唤出方式（把某建筑设为可配置）：

// Block 构造函数
configurable = true;             // Block.java:258
// Build 内部类
@Override public void buildConfiguration(Table table) {
    table.button("热网总览", () -> new ThermalOverviewDialog().show()).size(160f, 60f);
}

只讲 2~3 个新 API

① arc.scene.ui.Dialog —— Dialog.java:29，extends Table。自带 public final Table cont, buttons;(:57)——正文加 cont，底部按钮加 buttons。显示 show()(:514)、关闭 hide()(:551)。

② Styles —— Styles.java：面板 grayPanel(:27)、文本按钮 flatT(:32)、标签 outlineLabel(:97)。

坑

  1. 正文必须加在 this.cont，按钮加在 this.buttons。
  2. show() 无参自动挂到当前 scene；hide() 关闭。
  3. UI 必须在主线程；后台线程刷 UI 用 Core.app.post(() -> ...)。
  4. 动态列表要 clearChildren() 重建，否则会叠加。
  5. 别忘了 configurable = true，否则 buildConfiguration 不被调。

import arc.graphics.Color;

import static com.thermal.mod.core.ThermalStats.*;

@Override

    super.setBars();
    addBar("thermal-temp", (BoilerBuild entity) -> new Bar(
        () -> "温度",
        () -> {
            float f = Mathf.clamp(

        },
        () -> Mathf.clamp(
            (entity.thermal.getTemperatureK() - entity.thermal.minTempK)
            / (entity.thermal.maxTempK - entity.thermal.minTempK))
    ));
}
