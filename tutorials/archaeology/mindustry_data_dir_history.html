默认路径演变
阶段 1：v33–v100（2018-03 ~ 2019-11，ucore → arc 早期）
平台默认数据目录
Windows%AppData%\Mindustry\（即 C:\Users\<你>\AppData\Roaming\Mindustry\）
Linux~/.mindustry/
macOS~/Library/Application Support/Mindustry/
设置方式：无任何启动参数，需改源码或直接移动/链接目录。
阶段 2：v93 起（2019-09，Steam 版特例）
Steam 版（steam || Version.isSteam）数据目录改为 游戏安装目录/saves/，与普通版分离。
阶段 3：v104 起（2020-02，v7 正式版，现行默认）
平台默认数据目录
Windows%AppData%\Mindustry\（不变）
Linux$XDG_DATA_HOME/Mindustry/，未设置时 ~/.local/share/Mindustry/
macOS~/Library/Application Support/Mindustry/（不变）
启动时修改方式演变（ClientLauncher.setup 源码）
v126 起（2021-03）：环境变量
MINDUSTRY_DATA_DIR=/自定义/路径 java -jar Mindustry.jar
源码：String dataDir = OS.env("MINDUSTRY_DATA_DIR");
v147 起（2024-11，现行）：JVM 参数（优先）
java -Dmindustry.data.dir=/自定义/路径 -jar Mindustry.jar
源码（当前 master v159.7-479）：String dataDir = System.getProperty("mindustry.data.dir", OS.env("MINDUSTRY_DATA_DIR"));
优先级：-D 参数 > 环境变量，均未设置时用上表默认路径。
通用隐式覆盖方式（无需官方参数，v126 之前也能用）
路径实现基于环境变量/系统属性的平台，直接覆盖底层变量即可改目录。优先级：官方参数（-Dmindustry.data.dir / MINDUSTRY_DATA_DIR）> 本表隐式覆盖 > 系统默认。
平台覆盖方式结果路径
Windows（全版本）set AppData=D:\自定义（v88 实测有效）D:\自定义\Mindustry（被套一层）
Linux v104+XDG_DATA_HOME=/自定义/自定义/Mindustry
Linux v104 前-Duser.home=/自定义/自定义/.mindustry
macOS-Duser.home=/自定义/自定义/Library/Application Support/Mindustry
源码：Windows 读 env("AppData")；Linux 读 XDG_DATA_HOME 或 user.home；macOS 读 user.home。注意 -Duser.home 会影响所有基于家目录的路径，副作用较大。
核验依据：Mindustry@master b3317f3（ClientLauncher.setup）、Vars.loadSettings；Arc@master 889dd888（OS.getAppDataDirectoryString）；Arc 历史提交 fb10d061（2019-12-25 Linux 路径改为 XDG）；Mindustry 历史提交 efa5c5db7b（v126，环境变量）、d65f226b3a（v147，-D 参数）、f7eea51066（v93，Steam saves/）；UCore OS.java（早期 ~/.mindustry）。
