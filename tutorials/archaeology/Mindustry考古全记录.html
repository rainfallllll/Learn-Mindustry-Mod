3.3 legacyCompatible 用法
mod.json 声明 "legacyCompatible": true，共三处生效：
位置作用
Mods.java:1161加载判定豁免（|| meta.legacyCompatible）
Mods.java:1311isOutdated() 版本检查豁免（&& !meta.legacyCompatible）
ModBrowserDialog.java:323模组浏览器不显示"不兼容"提示
注意：只豁免版本门禁，不豁免 API 兼容性——旧模组仍可能因 API 变更崩溃。
