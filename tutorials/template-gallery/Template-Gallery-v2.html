1. 工程骨架

模组能跑起来的四个基础文件

mod.json 模板

v159.7
模组的"身份证"：告诉游戏这个模组叫什么、主类在哪、要求什么游戏版本。
{
  "name": "example-mod",
  "displayName": "示例模组",
  "author": "你的名字",
  "description": "一句话介绍你的模组。",
  "version": "1.0.0",
  "main": "com.example.mod.ExampleModMain",
  "minGameVersion": "154",
  "java": true,
  "dependencies": []
}
官方对应物：模组规范。name / main / minGameVersion / java 为必字段；main 指向主类全限定名。见 example-mod/mod.json。
改哪里：改 name（英文短名，也是文件夹名）和 main（主类路径）；想依赖别的模组就在 dependencies 里填对方 name。

主类模板

v159.7
模组入口：游戏通过它加载你注册的所有内容。
package com.example.mod;

import arc.util.Log;
import mindustry.mod.Mod;
import com.example.mod.content.ModItems;
import com.example.mod.content.ModBlocks;

public class ExampleModMain extends Mod {

    @Override
    public void loadContent() {
        // 在这里调用你自己的内容注册类
        ModItems.load();
        ModBlocks.load();
        // v2：液体/天气/星球/科技树都在这里注册
        // ModTech.load();  // 科技树必须在所有 block 创建完之后

        Log.info("ExampleMod: 内容加载完成!");
    }

    @Override
    public void init() {
        // 所有内容加载完毕后的初始化逻辑
        Log.info("ExampleMod: 模组初始化完成!");
    }
}
官方对应物：mindustry.mod.Mod。生命周期两步——loadContent() 注册内容，init() 做后期初始化。Content 构造时自动调用 Vars.content.handleContent(this)（Content.java:20-23）。
改哪里：loadContent() 里加你写的 ModXxx.load()；init() 里放事件监听、命令注册。

build.gradle 模板

v159.7
Gradle 构建脚本：决定怎么把 Java 代码编译成游戏能用的 jar。
plugins {
    id 'java'
}

// Mindustry v159.7 使用 Java 17
sourceCompatibility = 17
targetCompatibility = 17

repositories {
    mavenCentral()
    maven { url 'https://jitpack.io' }
}

dependencies {
    // Mindustry 核心库（仅编译时需要，运行时由游戏提供）
    compileOnly "com.github.Anuken.Mindustry:core:v159.7"
    // Arc 引擎核心库
    compileOnly "com.github.Anuken.Arc:arc-core:889dd8880f"
}

sourceSets {
    main {
        resources {
            srcDirs = ['src/main/resources']
        }
    }
}

jar {
    manifest {
        attributes(
            'Main-Class': 'mindustry.mod.ModClassLoader'
        )
    }
    from('mod.json') { into '' }
}

buildDir = 'build'
官方对应物：官方构建体系。依赖坐标固定指向 v159.7 的 core 与 arc-core；Main-Class 必须是 mindustry.mod.ModClassLoader。
改哪里：一般不用改。换游戏版本时把 v159.7 和 889dd8880f 换成对应版本号。
