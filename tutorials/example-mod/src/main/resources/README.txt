此目录用于存放模组的资源文件。

贴图文件应放在：
  sprites/items/        —— 物品贴图（如 example-item.png）
  sprites/blocks/       —— 方块贴图（如 example-wall.png）

示例：
  src/main/resources/sprites/items/example-item.png
  src/main/resources/sprites/blocks/example-wall.png
  src/main/resources/sprites/blocks/max-one-damage-wall.png
